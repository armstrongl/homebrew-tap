# homebrew-tap

Homebrew formulae for tools by [@armstrongl](https://github.com/armstrongl).

## Install

```shell
brew tap armstrongl/tap
```

### Available formulae

| Formula | Description |
|---------|-------------|
| [nd](https://github.com/armstrongl/nd) | Coding agent asset management CLI |
| [rulebound](https://github.com/armstrongl/rulebound) | Generate static style guide websites from Vale linting packages |

```shell
brew install armstrongl/tap/nd
brew install armstrongl/tap/rulebound
```

Formulae are auto-generated by [GoReleaser](https://goreleaser.com) on each release.
